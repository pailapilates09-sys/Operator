Enter a record

A short guide for the team.

  1. Manager: fill Setup first. Add Locations, Team and Plans. Keep the issued IDs.
  2. Choose the sheet for your task. Trainers mainly use Classes, Attendance, Follow-ups and Equipment.
  3. Start on row 5. Each row represents one record. Grey ID cells are already filled.
  4. Copy existing IDs. Do not create a new Client ID when someone returns for another class.
  5. Use the dropdowns. Dates use YYYY-MM-DD; class times use 24-hour HH:MM; amounts use NPR.
  6. Correct the row. Keep the ID and update its fields. Do not delete completed records or sort a single column.
  7. Ask for more IDs when needed. Do not duplicate a file or restart its numbering. The technical handler will add another batch.

What happens next?

Google Sheets saves your edits. We will validate and combine the records later. The website does not yet show automatically updated business reports.
