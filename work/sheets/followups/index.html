Follow-ups

Record who needs a follow-up and when.

Who: Trainer / Manager
When: When a task is assigned or completed

Open Follow-ups sheetHelp inside the sheet

Three steps

  1. Use the next empty row from row 5. Keep the ID in column A.
  2. Fill the required fields and choose from the dropdowns. Copy IDs from the existing records.
  3. Read the Check column. Keep the row when finished; update its status rather than deleting it.
What to enter

One row per follow-up task; keep the row after completion.

FieldRequiredInstruction
Follow-up IDYesKeep the issued ID.
Client IDYesCopy the existing Client ID.
Staff IDYesCopy the existing Staff ID.
Due dateYesEnter YYYY-MM-DD.
ReasonYesChoose Enquiry, First visit, Renewal, Feedback, Return visit, Other.
StatusYesChoose Open, Done, Cancelled.
Completed dateIf applicableEnter YYYY-MM-DD. Required when the task is Done.
Source referenceIf applicableEnter source reference.

IDs connect the files. See how IDs work. Use the entry guide for sorting, corrections and more rows.
