Studio setup

Add locations, staff and plans once.

Who: Manager
When: Before staff start entering records

Open Studio setup sheetHelp inside the sheet

Three steps

  1. Use the next empty row from row 5. Keep the ID in column A.
  2. Fill the required fields and choose from the dropdowns. Copy IDs from the existing records.
  3. Read the Check column. Keep the row when finished; update its status rather than deleting it.
What to enter · Locations

One row per studio location.

FieldRequiredInstruction
Location IDYesKeep the issued ID.
Location nameYesEnter location name.
StatusYesChoose Active, Inactive.
What to enter · Team

One row per trainer or staff member.

FieldRequiredInstruction

What to enter · Plans

One row per offered plan. Add a new plan ID when terms or price change.
