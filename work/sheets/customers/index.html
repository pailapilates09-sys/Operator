Clients

Keep one record for each client.

Who: Manager
When: At the first enquiry, then update the same row

Open Clients sheetHelp inside the sheet

Three steps

  1. Use the next empty row from row 5. Keep the ID in column A.
  2. Fill the required fields and choose from the dropdowns. Copy IDs from the existing records.
  3. Read the Check column. Keep the row when finished; update its status rather than deleting it.
What to enter

One row per person, from first enquiry onward.

FieldRequiredInstruction
Client IDYesKeep the issued ID.
Client nameYesEnter client name.
Location IDYesCopy the existing Location ID.
Enquiry dateYesEnter YYYY-MM-DD.
Heard about usIf applicableChoose Walk-in, Referral, Instagram, Website, Phone, Other.
StageYesChoose Enquiry, Trial booked, Active, Paused, Left.
Assigned staff IDIf applicableCopy the existing Staff ID.
Contact referenceIf applicableEnter contact reference.

IDs connect the files. See how IDs work. Use the entry guide for sorting, corrections and more rows.
