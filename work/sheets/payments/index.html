Payments

Record receipts and refunds in NPR.

Who: Manager
When: When money is received or refunded

Open Payments sheetHelp inside the sheet

Three steps

  1. Use the next empty row from row 5. Keep the ID in column A.
  2. Fill the required fields and choose from the dropdowns. Copy IDs from the existing records.
  3. Read the Check column. Keep the row when finished; update its status rather than deleting it.
What to enter

One row per actual receipt or refund. Amounts are positive; the kind determines the direction.

FieldRequiredInstruction
Payment IDYesKeep the issued ID.
DateYesEnter YYYY-MM-DD.
Client IDYesCopy the existing Client ID.
Location IDYesCopy the existing Location ID.
Amount (NPR)YesEnter a number in NPR. Leave unknown amounts blank.
KindYesChoose Receipt, Refund.
MethodYesChoose Cash, Digital, Bank, Other.
Membership IDIf applicableCopy the existing Membership ID.
Original payment IDIf applicableCopy the existing Payment ID. Required for refunds.
Receipt referenceYesEnter receipt reference.
