Memberships

Track each client's plan and dates.

Who: Manager
When: When a client buys, renews or changes a plan

Open Memberships sheetHelp inside the sheet

Three steps

  1. Use the next empty row from row 5. Keep the ID in column A.
  2. Fill the required fields and choose from the dropdowns. Copy IDs from the existing records.
  3. Read the Check column. Keep the row when finished; update its status rather than deleting it.
What to enter

One row per client's plan purchase or renewal. A renewal gets a new membership ID.
